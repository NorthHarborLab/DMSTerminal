生产状态: **等待真实 DSM 验收**。认证桥身份伪造、WebSocket 协议错误和 HTTP 终端弃用/配额问题已实施代码修复, 本地及 Linux Node.js 22 回归通过。官方认证助手在目标套件用户下的运行权限仍未知, 不能将替身测试当作真实 DSM 认证成功的证明。

本次没有修改仓库可见性, 不以“零风险”结论批准部署。公开源码与开放运行服务是不同的风险边界。

## Git 提交与推送

每次同步时执行以下流程, 不将这些操作视为真实 DSM 部署验收:

1. 确认仓库、分支、远端和全部暂存范围; 不把本地索引、依赖或运行数据提交
2. 审阅 diff 与 `git diff --check`, 确认没有无关用户改动混入
3. 源码隐私与候选文件检查通过后, 使用中文 commit 消息和中性 Git 署名提交
4. 推送后验证本地与远端 commit 一致, 核对全部可达历史与仓库可见性, 再单独决定仓库是否改为公开

推送代码与修改 GitHub 仓库可见性是不同操作。提交/推送请求本身不授权把私有仓库改为公开。
